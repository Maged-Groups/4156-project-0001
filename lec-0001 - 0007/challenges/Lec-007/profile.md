## Final Challenge — Review Your Page

After completing all tasks, make sure that:

- [ ] All elements appear one below another.
- [ ] All colors work well together.
- [ ] Headings are clear and visually distinct from paragraphs.
- [ ] Sections have appropriate backgrounds and borders.
- [ ] Elements have suitable spacing inside and outside.
- [ ] The final page looks clean, simple, and professional.

## CSS Rules

Use only the following CSS properties throughout this practice:

- `color`
- `background-color`
- `border`
- `padding`
- `font-size`
- `margin`

## Important Notes

- Complete the tasks in order.
- Use CSS element selectors and the selectors specified in each task.
- Keep all page elements in their normal vertical flow.
- Make sure each task improves the appearance of the same page.
