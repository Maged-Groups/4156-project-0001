# Challenge

## Create a 10-Page Website

Create a complete website containing the following 10 pages:

- `index.html`
- `about.html`
- `services.html`
- `projects.html`
- `contact.html`
- `team.html`
- `blog.html`
- `faq.html`
- `gallery.html`
- `testimonials.html`

---

# General Requirements

For **every page**:

- Add Basic HTML structure
- Add a meaningful Page Title
- Add an Icon
- Add a Logo
- Add a Page Heading
- Add a `header`
- Add a `nav`
- Add a `main`
- Add an `aside`
- Add a `footer`
- Add navigation links to **all 10 pages**
- Make sure all navigation links work correctly
- Make the Logo link back to the Home page

---

# index.html — Home Page

- Add a main heading
- Add a short welcome message
- Add a list of the main website sections
- Add links to important pages
- Add a featured section
- Add at least 3 items with headings and descriptions

---

# about.html — About Page

- Add a main heading
- Add an introduction about the website/company
- Add a section about the website's mission
- Add a section about the website's vision
- Add a list of at least 5 values
- Add a section containing important information about the company

---

# services.html — Services Page

- Add a main heading
- Add at least 6 services
- Add a heading and description for every service
- Add a list of service features
- Add links to related pages
- Add a section for the most popular services

---

# projects.html — Projects Page

- Add a main heading
- Add at least 6 projects
- Add a title for every project
- Add a description for every project
- Add an image for every project
- Add a list of technologies used in the projects
- Add links to relevant project pages

---

# contact.html — Contact Page

- Add a main heading
- Add the company's contact information
- Add an address section
- Add phone information
- Add email information
- Add working hours
- Add a list of available contact methods
- Add links to relevant pages

---

# team.html — Team Page

- Add a main heading
- Add at least 6 team members
- Add an image for every team member
- Add the name of every team member
- Add the job title of every team member
- Add a short description for every team member
- Add a list of team departments

---

# blog.html — Blog Page

- Add a main heading
- Add at least 5 blog posts
- Add a title for every post
- Add an image for every post
- Add a short description for every post
- Add the author name
- Add the publication date
- Add a list of blog categories
- Add links to read the posts

---

# faq.html — FAQ Page

- Add a main heading
- Add at least 8 frequently asked questions
- Add an answer for every question
- Organize the questions into different categories
- Add a list of FAQ categories
- Add links to relevant pages

---

# gallery.html — Gallery Page

- Add a main heading
- Add at least 12 images
- Add a title or description for every image
- Organize the images into different categories
- Add a list of gallery categories
- Add links to other website pages

---

# testimonials.html — Testimonials Page

- Add a main heading
- Add at least 6 testimonials
- Add the customer name for every testimonial
- Add an image for every customer
- Add the customer's job title or role
- Add the testimonial content
- Add a list of customer benefits
- Add links to relevant pages

---

# Navigation Requirements

The `nav` on **every page** must contain links to all 10 pages:

- Home
- About
- Services
- Projects
- Contact
- Team
- Blog
- FAQ
- Gallery
- Testimonials

# Final Check DoD

Before submitting your project:

- Make sure all 10 pages exist.
- Make sure every page has the required structure.
- Make sure every page contains the complete navigation.
- Test all navigation links.
- Make sure the Logo links to the Home page.
- Check that all images are displayed correctly.
- Check that all page titles are meaningful.
- Make sure the website can be navigated from page to page.
- Review your HTML structure before submission.
