0 — Project setup

Everything below is mandatory.

Required CDN links (inside <head>)

<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>

<link rel="stylesheet"
      href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.2/css/all.min.css"
      crossorigin="anonymous" referrerpolicy="no-referrer" />

Hard “do not” list

  • No gradients anywhere: no bg-gradient-*, no bg-linear-*, no bg-radial-*.
  • No text gradients: no bg-clip-text + text-transparent.
  • No inline <svg> icons — all icons must come from Font Awesome.
  • No images, no external fonts, no frameworks (Bootstrap, etc.).
  • No custom <style> blocks or arbitrary CSS — utilities only.
  • No JavaScript except the optional year script in the footer.

9 — Accessibility checklist

  • Page language set: <html lang="en">.
  • Exactly one <h1> — the hero headline. Section titles use <h2>, cards use <h3>.
  • Navbar has aria-label="Main navigation"; nav links are inside a <ul>.
  • Splitter wrapper has role="separator" and its lines have aria-hidden="true".
  • All decorative icons have aria-hidden="true" and carry no text alternative.
  • All buttons and links show a visible focus-visible outline of 2px with offset 2.
  • Every <a> has meaningful text — no “click here”, no empty links.
